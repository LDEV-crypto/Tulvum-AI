# PYTORCH - WHEN TO USE?

## 1. Working With Numerical Data

Use PyTorch when working with numerical data.

You may want to store:

* Token IDs
* Embedding Vectors
* Model Weights
* Attention Scores
* Training Data
* Positional Encodings
* Gradients
* Predictions

And much more!

## 2. Model Calculations

Use PyTorch when performing calculations inside your neural network.

Examples include:

* Matrix Multiplication
* Vector Operations
* Activation Functions
* Normalization
* Attention Calculations
* Linear Transformations

## 3. Training

PyTorch is especially useful when training AI models.

It provides tools for:

* Forward Propagation
* Backpropagation
* Gradient Calculation
* Loss Calculation
* Weight Optimization

## 4. GPU Acceleration

PyTorch can use GPUs to accelerate calculations.

This is particularly useful when:

* Training large models.
* Processing large batches of data.
* Performing large matrix multiplications.

## 5. Automatic Differentiation

PyTorch has a feature called Autograd.

Autograd automatically calculates gradients, which are needed for backpropagation.

This saves you from manually calculating gradients for every parameter.

## 6. Saving and Loading

PyTorch can save and load:

* Model Weights
* Model Checkpoints
* Tensors
* Optimizer States

This allows you to continue training without starting over.

## Conclusion

PyTorch is useful for almost everything involving numerical computation inside an AI model.

You don't necessarily need it for tokenization, BPE, or text processing, but it becomes extremely useful when building and training your neural network.
