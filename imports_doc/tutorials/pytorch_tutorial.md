# PYTORCH - TUTORIALS

This document teaches you the basics of PyTorch and how to use it when developing AI models.

# 1. Installing PyTorch

First, install PyTorch.

Run this command in your terminal:

```bash
pip install torch
```

Import it into your Python file:

```python
import torch
```

# 2. Creating Tensors

Tensors are PyTorch's primary data structure.

They store numerical data in different dimensions.

```python
import torch

x = torch.tensor([1, 2, 3, 4])

print(x)
```

You can also create tensors with multiple dimensions:

```python
x = torch.tensor([
    [1, 2],
    [3, 4]
])
```

# 3. Tensor Dimensions

Tensors can have different numbers of dimensions.

```python
import torch

one = torch.tensor([1, 2, 3])

two = torch.tensor([
    [1, 2],
    [3, 4]
])

three = torch.randn(2, 3, 4)

print(one.ndim)
print(two.ndim)
print(three.ndim)
```

Output:

```text
1
2
3
```

# 4. Tensor Operations

PyTorch supports mathematical operations on tensors.

```python
import torch

a = torch.tensor([1, 2, 3])
b = torch.tensor([4, 5, 6])

print(a + b)
print(a - b)
print(a * b)
print(a / b)
```

# 5. Tensor Shapes

You can inspect the shape of a tensor.

```python
import torch

x = torch.randn(3, 4)

print(x.shape)
```

Output:

```text
torch.Size([3, 4])
```

The tensor has 3 rows and 4 columns.

# 6. Data Types

PyTorch supports different numerical data types.

Some examples:

* `torch.float32`
* `torch.float16`
* `torch.float64`
* `torch.int32`
* `torch.int64`
* `torch.bool`

Example:

```python
import torch

x = torch.tensor([1, 2, 3], dtype=torch.float32)

print(x.dtype)
```

# 7. Automatic Differentiation

PyTorch has a feature called Autograd.

It automatically calculates gradients.

```python
import torch

x = torch.tensor(5.0, requires_grad=True)

y = x ** 2

y.backward()

print(x.grad)
```

Output:

```text
tensor(10.)
```

The gradient tells us how the output changes when the input changes.

# 8. Using the GPU

PyTorch can perform calculations on GPUs.

First, check whether CUDA is available:

```python
import torch

print(torch.cuda.is_available())
```

If CUDA is available, you can move a tensor to your GPU:

```python
x = torch.tensor([1, 2, 3])

if torch.cuda.is_available():
    x = x.to("cuda")
```

# 9. Neural Network Modules

PyTorch provides `torch.nn` for creating neural network components.

For example:

```python
import torch
import torch.nn as nn

layer = nn.Linear(10, 5)

x = torch.randn(1, 10)

output = layer(x)

print(output)
```

This creates a linear layer that accepts 10 input features and produces 5 output features.
